# Реферальная программа DuoPoker

## Как это работает

1. Каждый игрок получает **уникальный код** (на основе ника) при регистрации или первом входе.
2. Ссылка для приглашения: `https://duopoker.ru/lobby?ref=ВАШ_КОД`
3. Новый игрок указывает код при **регистрации** или в профиле в течение **7 дней** после создания аккаунта.
4. Когда приглашённый становится **активным**, он засчитывается рефереру.

## Кто считается «активным» рефералом

Все условия одновременно:

| Условие | Значение |
|---------|----------|
| Email | Подтверждён (`emailVerified`) |
| Возраст аккаунта | ≥ 24 часа |
| Раздачи | ≥ 5 завершённых раздач на платформе (не бот-столы) |

Пока условия не выполнены — статус `PENDING`. После — `ACTIVE`.

## Градация наград

Награды выдаются **вручную** в профиле (кнопка «Забрать»), когда набрано достаточно активных рефералов. Каждый уровень — один раз.

| Уровень | Активных рефералов | Награда |
|---------|-------------------|---------|
| 1 | 1 | 1 000 фишек |
| 2 | 3 | 3 000 фишек + вся косметика **Bronze** |
| 3 | 5 | 5 000 фишек + подписка **Silver** (30 дней) |
| 4 | 10 | 15 000 фишек + подписка **Gold** (30 дней) |
| 5 | 25 | 50 000 фишек + подписка **Platinum** (30 дней) |
| 6 | 50 | 100 000 фишек + подписка **Black** (навсегда) |

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/referrals/me` | Код, статистика, milestones |
| POST | `/api/referrals/apply` | Применить код `{ code }` |
| POST | `/api/referrals/claim/:level` | Забрать награду уровня 1–6 |

Регистрация: `POST /api/auth/register` с опциональным полем `referralCode`.

## База данных

Миграция `20260607000000_referrals`:

- `referral_codes` — код пользователя
- `referrals` — связь реферер ↔ приглашённый
- `referral_reward_claims` — полученные уровни наград

## Отслеживание раздач

При переходе раздачи в статус `COMPLETE` в `game-session.ts` вызывается `recordReferralHands()` для всех человеческих игроков за столом.

## Ограничения

- Один реферер на аккаунт (нельзя сменить код после привязки).
- Нельзя указать свой код.
- Саморефералы и повторное применение кода запрещены.
