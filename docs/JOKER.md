# Джокер (классический «расписной»)

Карточная игра на **взятки** для **4 игроков** (допустимо 3–2 по договорённости). Цель — набрать максимум очков за **24 сдачи** (~1–2 часа).

## Колода

- Масти: пики, червы, бубны, трефы.
- Старшинство: **6, 7, 8, 9, 10, валет, дама, король, туз**.
- **2 джокера** — особые карты (см. ниже).

## Структура партии (4 пульки)

| Пулька | Сдач | Карт на руку |
|--------|------|--------------|
| 1 | 8 | 1 → 8 (растёт) |
| 2 | 4 | 9 |
| 3 | 8 | 8 → 1 (убывает) |
| 4 | 4 | 9 |

## Джокеры

- Могут играть как **6♠** или **6♣**, либо объявляться **старшей/младшей** картой взятки, либо **задавать масть** для остальных (с ограничениями из полных правил).
- При двух джокерах в одной взятке побеждает **последний** сыгранный (или по правилу «не подряд» — см. домашний регламент).

## Ход сдачи (кратко)

1. **Тузование** — определяет первого сдающего.
2. **Раздача** по часовой стрелке; **козырь** — открытая карта (или без козыря, если джокер).
3. **Заявки** (0…число карт) — сумма заявок ≠ числу розданных карт (сдающий не может «закрыть» равенство).
4. **Розыгрыш взяток** — обязательно следовать масти, иначе козырь или снос.
5. **Подсчёт очков** по таблице (пас, 1–9 взяток, премии за пульку, штраф «хишт»).
